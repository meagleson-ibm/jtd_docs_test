# Upload Bulk Test Plans

You can upload Bulk Test Plans on the Test Plan page by uploading a properly formatted .csv file that contains the required Test Plan fields.

Uploading Test Plans requires a properly formatted .csv file that contains the following required fields. The Description Field is the only nonrequired field.

-   TestPlanName \(must be unique\)
-   TestPlanDescription
-   Type
-   Subtype
-   Equipment
-   MeasurementLibrary
-   Algorithm

To navigate to the Test Plan page:

-   From the Intelligent Design app, click the **Switcher** icon and select **Intelligent Test**. The Test Plan page opens.

**Note:** Only Test Engineer Administrators and Testers can create, edit, delete, export, import, upload, or archive Test Plans.

1.  On the Test Plan page, click the **Import** test plans icon in the menu bar next to the **Create** control. The Import Test Plan Modal opens.

    **Note:** Hover text displays for menu bar icons.

2.  Select **Choose File** and browse to the csv file on your computer that contains the bulk upload.

3.  Select **Open** to upload the file. The Uploaded Test Plans display in the Test Plan table in no particular order.

    **Note:** If any of the test plan names exist in the application before upload, the bulk upload fails. Test Plan names **MUST** be unique.
