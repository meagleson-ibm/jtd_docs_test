# Notifications in Intelligent Design and Intelligent Test

Intelligent Design and its companion module,Intelligent Test, provide real-time in-App and email notifications. In-App notifications within each application are application specific and display within their respective applications. Users can access the notifications panel within Intelligent Design and Intelligent Test.

Intelligent Design Notifications display for authorized users when the following events occur. Authorized user is defined as team member status, or macro owner status.

-   User is added to a team
-   Teams are added to a project \(and you are a team member\)
-   User is assigned as a Macro Owner
-   Macro that you own is changed

Intelligent Test Notifications display for authorized users when the following events occur. The authorized user is defined as creator of a test plan or test bench job.

-   Status of the test plan you created is updated
-   Status of test bench job you created is updated
-   Receipt of test bench results for test plan creators

Intelligent Design and Intelligent Test Email Notifications

**Email Notifications**

Authorized users receive email notifications about records they are associated with when those records are changed in any of the following ways.

-   Changes to status of macro records assigned to user
-   When they are assigned to a macro
-   When they are assigned to a team
-   When a team the user is on is added to a project
-   Changes to status of Test Plan on which the user is the creator
-   TestBench results are received on a job where the user is the creator

-   **[Accessing the Notification Panel](../id_docs/accessing_the_notifications_panel.md)**  
Within Intelligent Design and Intelligent Test users can access a **Notications Panel** that displays real-time alerts that are related to users' projects, macros, teams, and test plans.
