# Creating Devices from PCELL

You can create multiple devices from PCELL information that has been pushed to Intelligent Design.

To create a Device, you must be on the **Design View** tab in a Project, and must be viewing the **Device List**.

1.  On the **Design View** tab, click **Create Device** \> **Create from PCELL**.

2.  Select the PCELLs you want to import Devices from, and click **Next**.

3.  Select the Number of devices you want to create from each PCELL \(maximum = 100\).

4.  Confirm the accuracy of the Aspects and click **Create** to finishing creating the Devices

    **Note:** Devices are created under a specific Macro and can only be used for the Macro they are created under.
