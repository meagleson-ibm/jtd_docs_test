# Getting Help

If you continue to experience issues:

1.  **Collect Diagnostic Information:**
    -   Process ID of failed job
    -   Error logs from errorlog table
    -   Process log details from processlog table
    -   Application container/pod logs
2.  **Contact Support:**
    -   Provide all diagnostic information
    -   Include configuration details \(without sensitive data\)
    -   Describe steps to reproduce the issue
