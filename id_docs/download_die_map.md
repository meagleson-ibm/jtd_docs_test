# Download a Die Map

Downloading a die map allows a user to save a copy for backup or to use for creating other Wafer Definitions..

To navigate to Die Management:

-   From the Intelligent Design app, click the **Switcher** icon and select **Intelligent Test**. On the left side of the Intelligent Test page, click **Wafer Management**. The Wafer Management page opens. Click any existing Wafer Definition to view the Wafer Definition in detail.

1.  On the Wafer Definition detail page, click **Hamburger Icon** for a given die map and click **Download**.

2.  A dialogue opens, allowing the user to save the die map as a JSON file. Click **Save** to save the die map to the local filesystem.
