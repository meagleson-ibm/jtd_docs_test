# Creating a new Technology

Project Administrators can create new Technologies from the **Technology** tab.

**Note:** Only Project Administrators can create, edit, or delete Technologies.

1.  Click your profile icon, then select **Administration configuration**.

2.  On the **Technology** tab, click **Create Technology**.

3.  Type a unique **Technology Name**.

4.  Type a **Description** for the Technology.

5.  Select the **Technology Owner** from the list of users.

6.  Select the **Status** to be Active or Inactive.

7.  Click **Create**.
