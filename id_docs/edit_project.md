# Editing a Project

Project Administrators can edit Projects on the **All Projects** tab.

**Note:** Only Project Administrators can create, edit, or delete Projects.

1.  On the **All Projects** tab, select **Edit** from the **Actions** list for the Project you want to edit.

2.  On the Attributes tab, you can modify the **Project Name**, **Purpose** in Testsite projects\), and **Description**, select a new **Coordinator**, or select one or more **Padset Collections**.

    **Note:** In Testsite projects, any updates to the Testsite Project level purpose field are reflected in the macros within the project. If a Project Administrator attempts to edit or delete a Project's **Purpose** field that is used in a macro within the project, the system displays a warning and blocks the edit/deletion. **You are attempting to remove purpose values that are currently being used in one or more macros. update the affected macros before editing or deleting this Purpose value.**

3.  Select a new **Coordinator** from the list of users.

4.  Click **Aspects**, then select **Edit** in the row for any Aspects you want to modify.

5.  To add, modify, or delete files that are attached to the Project, click **Attachments**.

    1.  To add an attachment, click **Upload**, navigate to the file, then click **Open**.

    2.  To download attachments, select the files that you want to download and click **Download**.

    3.  To delete attachments, select the files that you want to remove and click **Delete**.

6.  Click **Save**.
