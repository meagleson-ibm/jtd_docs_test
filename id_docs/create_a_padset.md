# Create a Padset

**Note:** Only Project Administrators can create, assign, edit, upload/download, or delete Padsets.

1.  Click your profile icon, then select **Administration configuration**.

2.  On the **Padset** tab, click **Create Padset**.

3.  Type a unique **Padset name**. This must be unique across the entire Intelligent Design application, but may be up to 500 characters long.

4.  Select the **Technology** this padset belongs to.

    Each Padset can be associated with exactly one Technology.

5.  Enter a **Description** for the Padset. This may be up to 1000 characters.

6.  Click **Next** to proceed.

7.  Click the **Pencil Icon** or the value of any Aspects you want to modify. When finished editing a value, click the **Check** to confirm the changes.

8.  Click **Next**.

9.  Review the Project information, then click **Create**.
