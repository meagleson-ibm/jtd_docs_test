# Configuration Management

Configuration Management is a centralized hub in IT for maintaining master data for core test entities. It enables users with appropriate roles to create, view, and manage Equipment, Measurement Libraries, Probes, and Assets.

**Note:** Only Testers and Test Engineer Administrators can create, update, or delete Equipment, Probes, and Assets.

-   **[Algorithm Management](../id_docs/algorithm_mgmt.md)**  
Use the following steps to create Equipment data.
-   **[Probe Management](../id_docs/probe_mgmt.md)**  
Create and manage Probes, which are physical probe interfaces used in testing.
-   **[Asset Management](../id_docs/asset_mgmt.md)**  
Create and manage Assets, which are physical infrastructure components, such as test cells, instruments, probe cards, or terminals.
