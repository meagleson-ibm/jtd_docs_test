# Editing a Device

To edit a Device, you must be on Design View tab in a Project, and must be viewing the Device List.

There are two ways to edit a Device. In the Device List and through the Edit Dialogue.

1.  On the **Design View** tabs, click the **Pencil Icon** next to the field to be edited. After making changes, click the **Check Icon** to save the changes. Only the visible fields can be edited, and only one at a time. The Device name cannot be edited this way

2.  To edit more aspect of the device, click the **Hamburger Icon** to the right of the screen and select Edit device. This opens the Device Details dialogue.

3.  Click the **Device Name** to make the Device's name editable

4.  Click the **Device Description** to make the Device's description editable

5.  Click any **Aspect** to make that Aspect editable

6.  After making edits to a field, click the **Check Icon** to save the changes. Clicking any check will save changes made to any field on the Device Details dialogue.

7.  Add or Edit any **Pads** associated with the Device.

    **Note:** If the value of **ILT3D** is set to **Both**, the Device displays both Frontside and Grindside pad-to-terminal mappings side by side.

8.  When done, click the **Project Name** as the top of the dialogue to return to the **Design View** tab.
