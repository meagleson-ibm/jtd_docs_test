# Configuring Realm of keycloak - JSON

You can accomplish the same goal to setup Keycloak either manually or by importing a JSON data. If you obtained JSON data, then skip the manual process and use the JSON procedure in this document.

Prerequisites:

-   The path of the themes for Intelligent Design service is mounted to be accessed from Keycloak in the deployment.
-   The Realm configuration file with JSON Format for Intelligent Design is prepared.

-   **[Modifying Realm configuration file](../../id_docs/installation/modify_realm_config_file.md)**
