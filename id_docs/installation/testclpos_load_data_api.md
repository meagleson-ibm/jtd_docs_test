# Loading TestCLPos data with API

1.  Access the **TestPlanManager** Swagger interface on the target system.

2.  Expand `test-cl-pos-controller`.

3.  Expand the `POST /testclpos/bulk` section.

4.  Click **Try it out**.

5.  Paste the `TestCLPos JSON` you created in [Preparing CenterLine Position data](centerline_pos_prepare_data.md) as **Request body**, and click **Execute**.

6.  Confirm the execution finished with status 200.

    **Note:** Uploading large JSON data files might cause a problem.
