# Verifying the existence of prerequisite backend services and data

User manager – essential user permission

1.  Access the **Access Control Manager** Swagger interface on the target system.

2.  Expand `team-controller`.

3.  Expand the `GET /teams` section.

4.  Click **Try it out**.

5.  Click **Execute**.

6.  Find the **Response** section and **Response body** next to `Code 200`and ensure it contains a list of team entities.
