# Preparing WaferDef data

1.  Access the **Die Wafer Manager** Swagger interface on the target system.

2.  Open **“Models”** \> **“WaferDefDTO”** and check the data model.

3.  Create `WaferDefDTO` data based on your environment, and save as a `JSON` file.
