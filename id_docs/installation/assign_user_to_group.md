# Assigning a user to a group

Assign users to a group using the Keycloak Admin console.

1.  Login to the Keycloak Admin console URL.

2.  Switch to the **intldsgn** realm.

3.  Click **Users**.

4.  Select the email address of the user you want to assign.

5.  Select the **Role mapping** tab, and click **Assign Role**.

6.  Select one ore more role names, then click **Assign**.

7.  Repeat steps 4 - 6 for each user.
