# Adding a group using the Keycloak admin console

1.  Select the realm you want to configure.

2.  Navigate to **Realm roles**.

3.  If a target role name is not found, click **Create role**.

4.  Enter a **Role name**, such as Project Administrator.

5.  Type a **Description** for the role.

6.  Click **Save**.
