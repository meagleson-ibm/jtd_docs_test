# Embedded variables for Input/Output/Device parameters

The following variables can be applied for Input/Output/Device parameters:

|Pattern|Description|Example|
|-------|-----------|-------|
|`$terminal`|Refers to the pad number connected to the specified terminal.|`$high`|
|`#aspectName`|Refers to the device aspect value associated with the specified `aspectName`.|`#width`|
|`@metaInfoName`|Refers to the `metaInfo` associated with the specified type. The following types can be applied: -   `deviceName`
-   `macroName`
-   `iltCLName`

|`@deviceName`|
