# Uploading List value data

User manager – essential user permission

1.  Access the **List Manager** Swagger interface on the target system.

2.  Expand `ordered-list-controller`.

3.  Expand the `GET /orderedlist/upload` section.

4.  Click **Try it out**.

5.  Click **Choose File** to select the .csv file.

6.  Click **Execute**.

7.  Verify the response to show status code 200 for data accepted.
