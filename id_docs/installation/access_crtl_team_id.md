# Using Access Control Manager Swagger to get the team ID

Open Access Control Manager Swagger to get the team ID you want to use.

1.  Access the Access Control Manager Swagger:

    `https://\{your\_host\_name\}/api/v1/abls/accessctlmgr/swagger-ui/index.html`

2.  Click the **Authorize** icon.

3.  Paste the access token you obtained above into the **Value** field.

4.  Expand team-controller.

5.  Expand the **GET /teams** section.

6.  Click **Try it out**.

7.  Click **Execute**.

8.  Find the **Response** section and **Response body** next to Code 200.

9.  Record the ID of your target team.
