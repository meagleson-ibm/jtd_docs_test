# intellifab-database-service

## Database Service

Service: intellifab-database-service

Purpose: This service included the legacy Datamigration service and the Datacleanup service invoked as a single FastAPI-based backend. This consolidation eliminates duplicate configuration, reduces maintenance overhead, and provides a single-entry point for all database operations.

-   **[Data Setup](../../id_docs/installation/ifds_data_setup.md)**  

-   **[Data Migration Process](../../id_docs/installation/ifds_data_migration_proc.md)**  
Purpose: To migrate legacy data into the Intelligent Design Database when required.
-   **[intellifab-data-cleanup-service](../../id_docs/installation/ifds_data_cleanup_svc.md)**  
Purpose: To cleanup the data based on the retention policy configured.

**Parent topic:**[Data deployment](../../id_docs/installation/data_deploy.md)
