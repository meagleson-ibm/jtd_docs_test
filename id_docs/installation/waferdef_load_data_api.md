# Loading WaferDef data with API

1.  Access the **Die Wafer Manager** Swagger interface on the target system.

2.  Expand `wafer-def-controller`.

3.  Expand the `POST /waferdef` section.

4.  Click **Try it out**.

5.  Paste the `WaferDefDTO JSON` you created in [Preparing WaferDef data](waferdef_prepare_data.md) as **Request body**, and click **Execute**.

6.  Confirm the execution finished with status 200, and locate its ID.

    **Important:** Keep note of this ID for later use.
