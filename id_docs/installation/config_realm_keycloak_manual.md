# Configuring Realm of keycloak - Manual

You can accomplish the same goal to setup Keycloak either manually or by importing a JSON data.

If you obtained JSON data, then skip the manual process \(this document\), and use the [JSON procedure](config_realm_keycloak.md).

-   The path of the themes for Intelligent Design service is mounted to be accessed from Keycloak in the deployment.
