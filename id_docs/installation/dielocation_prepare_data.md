# Preparing DieLocation data

1.  Access the **Die Wafer Manager** Swagger interface on the target system.

2.  Open **“Models”** \> **“DieLocationDTO”** and check the data model.

3.  Create `DieLocationDTO` data based on your environment, and save as a `JSON` file.

    **Note:** `waferdefId` must be set to the value kept in the previous step. There are usually multiple die locations for one wafer, and multiple `DieLocationDTO`s must be created accordingly.
