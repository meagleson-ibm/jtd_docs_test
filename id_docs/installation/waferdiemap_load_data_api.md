# Loading WaferDieMap data with API

1.  Access the **Die Wafer Manager** Swagger interface on the target system.

2.  Expand `wafer-die-map-controller`.

3.  Expand the `POST /waferdiemap` section.

4.  Click **Try it out**.

5.  Paste the `WaferDieMapWithDieLocationsDTO JSON` you created in [Preparing WaferDieMap data](testdiemap_prepare_data.md) as **Request body**, and click **Execute**.

6.  Confirm the execution finished with status 200.
