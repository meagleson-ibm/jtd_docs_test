# Generate Client secret

|\(A\) Configuration file name|\{Configuration file name with Json Format\}|
|\(B\) ID for client admin cli|admin-cli|
|\(C\) ID for Intelligent Design Application|id-application-client|
|\(D\) ID for Intelligent Design Test Application|intellifab-test-application-client|

1.  Click **Clients** in Left side panel.

    The clients with \(B\), \(C\), and \(D\) appear.

2.  Select **\(B\) ID for client admin cli**.

    The Configuration with several tabs for \(B\) appear.

3.  Select the **Credential** tab.

4.  Click **Regenerate** for Client Secret.

5.  Repeat steps 2 – 4 for \(C\) and \(D\).
