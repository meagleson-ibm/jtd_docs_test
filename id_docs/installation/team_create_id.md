# Creating a team in the Intelligent Design app

This document illustrates how to setup fictitious users in Intelligent Design, using sample emails with a common email domain like `@example.com`.

1.  Login to the Intelligent Design app as Project Administrator.

2.  Click the **User avatar** icon to see the **Administration configuration** menu.

3.  Click **Administration configuration**.

4.  On the Administration Configuration page, click **Team management**.

5.  Click **Create team**.

6.  Type a **Team name** and **Description** \(optional\) and click **Next**.

7.  Click **Add collaborator**.

8.  Select one or more users and click **Add**.

    For each added user, a role is assigned from the user profile. If multiple roles are assigned, and change the role within the team, then select appropriate role for that user.

9.  Click **Next**.

10. Review the name, description, and collaborators and click **Create**.
