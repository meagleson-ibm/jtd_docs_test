# Preparing MeasurementLibCmd data

1.  Access the **Equipment Manager** Swagger interface on the target system.

2.  Open **“Models”** \> **“MeasurementLibCmdDTO”** and check the data model.

3.  Create `MeasurementLibCmdDTO` data based on your environment, and save as a `JSON` file.

    **Note:** `measurementLibId` must be set to the value kept in the previous step. Sample Data:https://ibm.box.com/s/wdns2t08i1xmd15suxhqilohcl37yz96
