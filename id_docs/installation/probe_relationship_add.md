# Adding EquipmentType – Probe relationship with API

1.  Access the **Equipment Manager** Swagger interface on the target system.

2.  Expand `equipment-controller`.

3.  Expand the `POST /equipmenttypeprobe` section.

4.  Click **Try it out**.

5.  Create **Request body** and set `equipmentTypeId` and `probeId` based on your environment

    **Note:** These values were obtained in previous steps.

6.  Click **Execute**.

7.  Confirm the execution finished with status 200.
