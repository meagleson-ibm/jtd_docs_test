# Preparing WaferProjectMap data

1.  Access the **Die Wafer Manager** Swagger interface on the target system.

2.  Open **“Models”** \> **“WaferProjectMapDTO”** and check the data model.

3.  Create `WaferProjectMapDTO` data based on your environment, and save as a `JSON` file.

    **Note:** `waferDefId` and `projectId` must be set to the value kept in the previous step.
