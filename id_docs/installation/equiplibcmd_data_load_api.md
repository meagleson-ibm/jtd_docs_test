# Loading MeasurementLibCmd data with API

1.  Access the **Equipment Manager** Swagger interface on the target system.

2.  Expand `equipment-controller`.

3.  Expand the `POST /measurementlibcmd` section.

4.  Click **Try it out**.

5.  Paste the `MeasurementLibCmdDTO JSON` you created in [Preparing MeasurementLibCmd data](equiplibcmd_prepare_data.md) as **Request body**, and click **Execute**.

6.  Confirm the execution finished with status 200.
