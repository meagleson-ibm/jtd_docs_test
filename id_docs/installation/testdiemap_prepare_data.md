# Preparing WaferDieMap data

1.  Access the **Die Wafer Manager** Swagger interface on the target system.

2.  Open **“Models”** \> **“WaferDieMapWithDieLocationsDTO”** and check the data model.

3.  Create `WaferDieMapWithDieLocationsDTO` data based on your environment, and save as a `JSON` file.

    **Note:** `waferdefId` and `dieLocations` must be set to the value kept in the previous step.
