# Preparing CenterLine Position data

1.  Access the **TestPlanManager** Swagger interface on the target system.

2.  Open **“Models”** \> **“TestCLPosDTO”** and check the data model.

    The following properties are required:

    -   `clName:` String
    -   `xPos:` double
    -   `yPos:` double
3.  Create `TestCLPos` data based on your environment, and save as a `JSON` file.
