# Loading EquipmentType data via API

1.  Access the **Equipment Manager** Swagger interface on the target system.

2.  Expand `equipment-controller`.

3.  Expand the `POST /equipmenttype` section.

4.  Click **Try it out**.

5.  Paste the `EquipmentTypeDTO JSON` you created in [Preparing EquipmentType data](equipmgr_prepare_data.md), and click **Execute**.

6.  Confirm the execution finished with status 200, and locate its ID.

    **Important:** Keep note of this ID for later use.
