# Installing with Helm

1.  Customize the provided Helm chart values file to fit your own environment.

    **Tip:** See the [Helm chart reference page](../reference/id_ref_helm_values.md) for more information.

2.  Download and unpack the ID Helm Chart.

3.  Execute the following Helm command, substituting your own parameters when appropriate:

    `helm install -n <destination namespace\> intldsgn </path/to/downloaded/chart\> --values </path/to/values.yaml\>`
