# Loading DieLocation data with API

1.  Access the **Die Wafer Manager** Swagger interface on the target system.

2.  Expand `die-location-controller`.

3.  Expand the `POST /dielocation` section.

4.  Click **Try it out**.

5.  Paste the `DieLocationDTO JSON` you created in [Preparing DieLocation data](dielocation_prepare_data.md) as **Request body**, and click **Execute**.

6.  Confirm the execution finished with status 200, and locate its ID.

    Repeat this step for all `DieLocationDTO JSON`.

    **Important:** Keep note of this ID for later use.
