# Adding a group in the admin console

1.  Navigate to **User Management** and open the **Groups View**.

2.  Click **Add +**.

3.  Enter a **Group Name** and **Description**.

4.  Click **Save**.

5.  To add another group, repeat steps 2 - 4.

6.  Click **Close**.
