# Checking projectId for Target project

1.  Access the **Project Manager** Swagger interface on the target system.

2.  Expand `project-controller`.

3.  Expand the `GET /project` section.

4.  Click **Try it out**.

5.  Leave `page` and `pagecount` blank, and click **Execute**.

6.  Confirm the execution finished with status 200, and locate its ID.

    **Important:** Keep note of this ID for later use.
