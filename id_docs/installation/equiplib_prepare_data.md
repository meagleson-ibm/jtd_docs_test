# Preparing MeasurementLib data

1.  Access the **Equipment Manager** Swagger interface on the target system.

2.  Open **“Models”** \> **“MeasurementLibDTO”** and check the data model.

3.  Create `MeasurementLibDTO` data based on your environment, and save as a `JSON` file.
