# Loading WaferProjectMap data with API

1.  Access the **Die Wafer Manager** Swagger interface on the target system.

2.  Expand `wafer-project-map-controller`.

3.  Expand the `POST /waferprojectmap` section.

4.  Click **Try it out**.

5.  Paste the `WaferProjectMapDTO JSON` you created in [Preparing WaferProjectMap data](waferprojectmap_prepare_data.md) as **Request body**, and click **Execute**.

6.  Confirm the execution finished with status 200, and locate its ID.
