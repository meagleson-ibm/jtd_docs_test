# Adding Integration Roles

Add the `IntegrationRead` and `IntegrationWrite` roles.

1.  Login into the Keycloak Admin console and select the target realm.

2.  Select **Realm roles** in the navigation pane.

3.  Click **Create role**.

4.  Enter IntegrationRead for the **Role name** and add a description \(optional\).

5.  Click **Save**.

6.  Repeat steps 3 - 5 for the `IntegrationWrite` role.
