# Create Realm

|\(A\) Configuration file name|\{Configuration file name with Json Format\}|
|\(B\) ID for client admin cli|admin-cli|
|\(C\) ID for Intelligent Design Application|id-application-client|
|\(D\) ID for Intelligent Design Test Application|intellifab-test-application-client|

1.  Login to the Keycloak admin console.

2.  In the Master drop-down menu, click **Create realm**.

    The Create realm form opens.

3.  Click **Browse…**, navigate to the Resource file directory, and Select file \(A\).

    The resource file and the realm name appear.

4.  Click **Create**.
