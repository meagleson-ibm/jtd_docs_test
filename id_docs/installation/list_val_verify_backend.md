# Verifying the existence of prerequisite backend services and data

User manager – essential user permission

1.  Access the **List Manager** Swagger interface on the target system.

2.  Expand `ordered-list-controller`.

3.  Expand the `GET /orderedlist/download` section.

4.  Click **Try it out**.

5.  Click **Execute**.

6.  Find the **Response** section and **Response body** next to `Code 200`, which contains one or more CSV entries.
