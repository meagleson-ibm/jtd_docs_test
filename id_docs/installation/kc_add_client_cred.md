# Adding a Client Credential

After **Client Authentication** and **Authorization** are turned on during ClientID Creation, each ClientID has a **Credentials** tab.

[Add a ClientID](kc_add_clientid.md)

1.  On the Clients page, select the **Client list** tab, and click the **ClientID** that you created.

2.  On the **Credentials** tab, set the **Client Authenticator** and the **Client Secret**.


**Parent topic:**[Creating a ClientID for ID applications](../../id_docs/installation/create_client_id.md)
