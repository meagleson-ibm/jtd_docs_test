# Delete a Die Map

Deleting a wafer definition allows a user to clear unused wafer definitions from the wafer management screen..

To navigate to Die Management:

-   From the Intelligent Design app, click the **Switcher** icon and select **Intelligent Test**. On the left side of the Intelligent Test page, click **Wafer Management**. The Wafer Management page opens. Click any existing Wafer Definition to view the Wafer Definition in detail.

1.  On the Wafer Definition page, click **Hamburger Icon** for a given wafer definition and click **Delete** to open the Delete die map dialogue. Multiple die maps can be deleted at once by checking the boxes by their name and clicking the **Delete** button that appears at the top of the die map list.

2.  On the delete dialogue, click **Delete**completely erase the selected die maps and return to the Wafer Definition page. Clicking **Cancel** navigates back to the Wafer Detail page without erasing anything.
