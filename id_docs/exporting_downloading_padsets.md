# Export Padsets

A Padset is a unique set of Pads. A Padset is used by assigning it to a project, and each Padset can be used only one time. Use this procedure to bulk export padsets. Padsets are exported into a .csv file format for use either inside ID or outside of ID. Project Admins can export the Padsets, edit the Padsets, and upload the edited Padsets.

**Note:** Only Project Administrators can create, assign, edit, import, export, or delete Padsets.

1.  Click your profile icon, then select **Administration configuration**.

2.  On the Administration configuration page, click **Padset**. The **Padset** page opens.

    -   Click a checkbox to select the **Padsets** you want to export and then click **Export** in the table menu bar. The **Padsets** are exported and a prompt displays confirming the **Export**.

        ![Success Prompt for Export Padsets](_images/id_admin_export_padsets_prompt.jpg "Success Prompt for Export (Download) Padsets")

    -   Click the **Folder Icon** in the prompt to access the folder containing the Padsets.
    The Padsets remain in the list of Padsets on the Padsets page.

    **Note:** Padsets are exported in .csv format and can be edited and reimported. See [Import Padsets](upload_download_padsets.md).
