# Navigating to Disposition Pages

To view, create, and edit lot and wafer dispositions, you need to navigate to the Disposition landing pages using the procedure below.

1.  On the Test Results Page, click the **Test Program** that has the lot or wafer disposition to be accessed.

2.  On the Test Program Detail Page, click the appropriate **Breadcrumb Link** to access either the Lot or Wafer level. Click the link immediately next to the Test Result breadcrumb to access the Lot View, and the click the breadcrumb next to the Test Program Name to access the Wafer View.

3.  One on the Lot or Wafer Landing Page, click **Lot Disposition** or **Wafer Disposition** to access the Disposition Landing Page.
