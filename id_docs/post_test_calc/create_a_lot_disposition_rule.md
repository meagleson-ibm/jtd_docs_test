# Create a Lot Disposition Rule

The steps for creating Lot Disposition Rules

1.  On the Lot Disposition Page, click **Create Disposition Rule**.

    The Create a lot disposition rule page opens.

2.  Select a **Test Level** and **Family Code** for the rule.

    These decide the timing of when the rule applies. Note that two rules with the same Test Level and Family code cannot exist for the Lot.

3.  Set the **Attribute Thresholds** for the disposition rule. Each available action, Scrap, Retest, Hold, Rework and Non-pass can have a threshold number and percentage of wafer that fail test action before failing the lot. To set these, click the numbers in the **Num Wafers Failed** and **Pct Failed \(%\)** columns and insert the relevant numbers.

4.  Click the **Enabled Toggle Switch** to enable the rule.

5.  Once the **Test Level**, **Family Code** and **Attribute Thresholds** are set, click **Create** to finalize and create the rule.
