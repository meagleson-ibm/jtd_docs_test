# Reload data to recalculate test results

You can select a lot and PNP combination within a technology and confirm the creation submission of the corresponding TEDs files for recalculation and retransmission to the ISDW database through its low priority ETL folder over SFTP.

1.  In the Post Test Calculation app, click **Test Results** and select a **Test Program**.

2.  Select the **Calculations** tab.

3.  Click **Reload Data**.

4.  Select the Lot IDs that you want to reload calculations for.

5.  Select whether you want to Transmit data to ISDW when the recalculations are complete.

6.  Click **Recalculate**.

    The **Recalculation process started** notification appears.

7.  Click the **Activity Log** button in the notification to verify that the selected log is updated in the Activity log with the job ID.
