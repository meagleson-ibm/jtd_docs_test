# Viewing Wafer Data

1.  On the Test Results page, select the **More Options** icon in the row for a Test Program, and click **Wafer Data**.

    **Tip:** You can also access wafer data by clicking on a Wafer ID in the [Lot Summary](view_lot_data.md) table.

    The Wafer Overview page displays a summary table of the parameters tested on this wafer, including the following data:

    -   **Parameter Name**
    -   **Test Level**
    -   **Macro ID**
    -   **Num Obs** - The number of “valid observations."
    -   **Yield**
    -   **Median**
    -   **Mean**
    -   **Min**
    -   **Max**
    -   **ptile25** - 25th percentile
    -   **stdev** - Standard deviation.
    **Tip:** You can use filters to control ranges for specific aggregate columns within the Lot and Wafer Summary pages.

    ![Filter Lot and Wafer columns by data range](../_images/ptc_filter_wafers.jpg)

2.  To [view test results at the chip level](view_chip-level_params.md), click **Wafer Test Results**, and then click on a Test Program.

3.  To view the Wafer Disposition Status, select the **Wafer Disposition** tab.
