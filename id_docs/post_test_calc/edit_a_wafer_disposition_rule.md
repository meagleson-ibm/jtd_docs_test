# Edit a Wafer Disposition Rule

1.  While on the Wafer Disposition Page, click **the three dots icon** in the disposition rule row, then click **Edit**. This opens the Edit wafer disposition rule page.

2.  On the General Information tab, the **Wafer Disposition rule name**, **Disposition Message** and **Enabled** status can be edited..

3.  Click **Rule Statement**to navigate to the Rule statement tab.

4.  Edit the rule by clicking any of the **Condition**, **Parameter**, **Property**, **Operator**, and **Value** to edit or completely change the rule.

5.  Click the current **Action** to select a new action to perform when the rule is triggered.

6.  To remove either the Rule or Action and start over, click the **X** icon at the end of the row.

7.  Click **Save** to finalize and save the new disposition rule.

8.  To delete a disposition rule click **the three dots icon** in the disposition rule row, then click **Delete**. Confirm the deletion by clicking **Delete** on the prompt that appears. Deleting a rule cannot be undone.
