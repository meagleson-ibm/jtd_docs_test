# Create a Wafer Disposition Rule

The steps for creating Wafer Disposition Rules

1.  While on the Wafer Disposition Page, click **Create disposition rule**. This opens the Create wafer disposition rule page.

2.  Enter a **Wafer Disposition rule name** and **Disposition Message** for the rule.

3.  Use the **Enabled** toggle to enable to rule.

4.  Click **Next** to proceed to Rule statement.

5.  Create the rule by selecting a **Condition**, **Parameter**, **Property**, **Operator**, and **Value**for the **Passing Criteria**.

6.  Click the **+ button** below **On Failure** to select the action to perform when the rule is triggered.

7.  To remove either the **Passing Criteria** or **On Failure** action and start over, click the **X** icon at the end of the row.

8.  Click **Finish** to finalize and save the new disposition rule.
