# Creating a Filter Set

You can apply filter sets to limit the number and type of results that are displayed in the Test Results table. You can apply previously saved filter sets, or you can create a new filter set to use.

1.  Click the filter icon. ![Filter icon](../_images/filter.jpg)

2.  Click **Create Filter Set**.

3.  Type a name for the filter set, then click **Save**.

4.  Select the **Technology** for the test results you want to view.

5.  Select the **Test Level** for the test results you want to view.

6.  Specify a **Start** and **End** date to filter the results by the date the tests were run.

7.  Click **Apply** to view the filtered results.
