# Edit a Lot Disposition Rule

1.  While on the Lot Disposition Page, click **the three dots icon** in the disposition rule row, then click **Edit**. This opens the Edit a lot disposition rule page.

2.  The **Test Level** and **Family Code** for the rule can be changed, to alter the timing of when the rule applies. Note that two rules with the same Test Level and Family code cannot exist for the Lot.

3.  The **Attribute Thresholds** for the disposition rule can be changed by clicking the numbers in the **Num Wafers Failed** and **Pct Failed \(%\)** columns and typing in new numbers.

4.  Click the **Enabled Toggle Switch** to enable or disable the rule.

5.  Click **Save** to finalize any edits to the rule, or click **Cancel** to discard the changes and close the window.

6.  To delete a disposition rule click **the three dots icon** in the disposition rule row, then click **Delete**. Confirm the deletion by clicking **Delete** on the prompt that appears. Deleting a rule cannot be undone.
