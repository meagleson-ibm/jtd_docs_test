# Edit a Wafer Definition

Editing a wafer definition allows a user to adjust and correct its details as needed.

**Note:** Only users who are on teams assigned to the project that is referenced in a Wafer Definition can view, edit, delete, or download that Wafer Definition.

To navigate to the Wafer Management page:

-   From the Intelligent Design app, click the **Switcher** icon and select **Intelligent Test**. On the left side of the Intelligent Test page, click **Wafer Management**. The Wafer Management page opens.

1.  On the Wafer Management page, click **Hamburger Icon** for a given wafer definition and click.**Edit** to open the Edit wafer definition page.

2.  Alternately, Click the **Wafer Name** to open the Wafer Detail page. Click the **Hamburger Icon** in the corner of the Wafer Visualization pane and click **Edit** to directly open the Define die types page.

3.  The Edit wafer definition page contains three tabs, Wafer Attributes, Wafer Parameters, and Wafer die types.

4.  On the Wafer attribute tab, the basic attributes of the Wafer can be changed. Note that changing the **Technology** for the wafer will also change which associated **Project** is available to be selected. The Wafer's **Notch Orientation** can also be changed, as can the definition's **Name**. Whether or not the wafer definition is set as a default can also be changed via the check box.

5.  On the Wafer Parameters tab, the 22 Wafer parameters can be altered. Clicking each parameter's value field opens that field for editing.

6.  On the Define die types tab, the die chart can be used to set the die type for each die. This can be done one by one by selecting **N for None**, **F for Full**, **P for Partial**, or **E for Edge** in each die's drop down. Individual dies can also be set by clicking them on the **Wafer Map** to open up Assign die type dialogue.

7.  Die types can also be set in groups or in bulk. To assign them in a group, check the box for each die to define, then click **Assign** at the top of the die chart. To assign the die type for all dies at once, check the box at the top of the die chart so it shows a check mark, and click **Assign**. Both methods open the Assign die type window.

8.  The Assign die type window shows the number of die currently selected to have their type assigned. Using the drop down, select **None**, **Full**, **Partial**, or **Edge**, then click **Apply**. All selected dies will change to the selected type.

9.  **Note:** Navigating away from the Wafer die types tab will void any changes made to the die map. This limitation does not apply to the Wafer Attributes or Wafer parameters tabs.

    **Note:** The **Save** button is only clickable when all required fields have valid data.

    Click **Save** to save any change made, or **Cancel** to discard them. Either selection navigates to the Wafer Management page.
