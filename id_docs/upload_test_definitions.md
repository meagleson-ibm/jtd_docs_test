# Upload Bulk Test Definition

You can now upload Bulk Test Definitions on the Test Definition page by uploading a properly formatted .csv file that contains the required Test Definition fields.

Uploading Test Definitions requires a properly formatted .csv file that contains the following required fields. The Description Field is the only non-required field.

-   TestDefinitionName \(must be unique\)
-   TestDefinitionDescription
-   Type
-   Subtype
-   Equipment
-   MeasurementLibrary
-   Algorithm

To navigate to the Test Definition page:

-   From the Intelligent Design app, click the **Switcher** icon and select **Intelligent Test**.
-   From the Test Plan page, click **Test Definition** from the navigation menu.

**Note:** Only Testers can create, edit, delete or upload Test Definitions.

1.  On the Test Definition page, click the **Import** test definitions icon in the menu bar next to the **Create** control. The Import Test Definitions Modal opens.

    **Note:** Hover text displays for menu bar icons.

2.  Select **Choose File** and browse to the csv file on your computer that contains the bulk upload.

3.  Select **Open** to upload the file. The Uploaded Test Definitions display in the Test Definition table in no particular order.

    **Note:** If any of the test definition names exist in the application, the bulk upload fails. Test Definitions names **MUST** be unique.
