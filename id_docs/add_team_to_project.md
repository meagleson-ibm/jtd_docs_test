# Assigning a Team to a Project

Project Administrators can edit Team assignment to a Project on the All Projects tab.

**Note:** Only Project Administrators can create, edit, or delete Teams

1.  On the **All Projects** tab, select **Edit** from the **Actions** list for the Project you want to edit.

2.  On the **Attributes** tab, expand **Teams**.

3.  Select or deselect a team.

4.  Click **Save**.

    **Note:** If the target project is not listed in the **All Projects** tab, follow the "Post data migration steps" in the *Intelligent Design Installation and Configuration Guide*. [https://ibmdocs-test.dcs.ibm.com/docs/en/intelligent\_design\_test?topic=post-data-migration-steps](https://ibmdocs-test.dcs.ibm.com/docs/en/intelligent_design_test?topic=post-data-migration-steps)
