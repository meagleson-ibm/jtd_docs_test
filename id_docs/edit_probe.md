# Editing Probe data

You can edit existing Probe cards on the **Probe Management** tab.

1.  On the **Configuration Management** page, select the **Probe Management** tab.

2.  In the table, expand the Equipment that contains the probe card, select the **More** menu next to the probe you want to update, and click **Edit**.

3.  On the **Probe attributes** tab, you can update any of the following fields:

    -   **Probe Name**
    -   **Vendor**
    -   **Model**
    -   **PadPitchX**
    -   **PadPitchY**
    -   **Equipment**
    -   **Layout**
    -   **Min Temperature**
    -   **Max Temperature**
    -   **Material type**
4.  On the **Probe aspects** tab, you can add or delete measurement libraries.

5.  On the **Probe Aspect Template**, you can add probe aspect key-value pairs.

6.  Click **Save**.


On the **Probe Management** tab, you can also click the **More** menu next to a probe to **View**, **Copy**, or **Delete** the probe, or **Download** it as a .csv file for reporting purposes.

**Note:** You cannot delete a probe that is used in a Test Definition or Test Plan.
