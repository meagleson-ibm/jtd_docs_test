# Archiving a test plan

When a Test Plan is outdated or no longer used, you can archive it to remove it from your daily view.

Archived test definitions are moved to the Inactive tab on the Test Plan page. Archived test definitions are excluded from the Test Bench **Test Plan** section, but remain searchable and retrievable. You can restore archived Test Plans to the Active list if needed.

**Note:** Only Test Engineer Administrators and Testers can create, edit, delete, export, import, upload, or archive Test Plans.

**Note:** Users who are on teams that are assigned to the project that is referenced in a Test Plan are the only ones who can view, edit, delete, export, import, or archive the Test Plan.

1.  In the Test Plan table, select one or more Test Plans that you want to archive, and click **Archive**.

2.  Click **Archive** on the verification window.


-   **[Restoring a test plan](../id_docs/restore_test_plan.md)**  
If you need to use a Test Plan that has been archived, you can restore it from the Inactive tab.
