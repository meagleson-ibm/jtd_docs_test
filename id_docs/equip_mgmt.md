# Creating Equipment data

Create and manage Equipment master data that serves as the foundation for Measurement Libraries.

1.  On the **Configuration Management** page, select the **Algorithm Management** tab.

2.  Click **Create Equipment**.

3.  Type the **Equipment Name**, **Vendor**, and **Type**.

4.  Select the **Test Script Type**.

5.  Enter the **Model** and a **Description**.

6.  Click **Next**.

7.  Click **Add Measurement Library**.

8.  Type a unique **Name** for the library.

9.  Type a **Description** for the library.

10. Click **Upload**, navigate to a Library \(.lib\) file, and click **Open**.

    **Note:** Each Equipment asset can have multiple Measurement Libraries with the same name. Each is an independent copy. Updates to one equipment's library do not affect other Equipment assets' libraries.

11. Click **Next**.

12. To upload a probe aspect template, click Upload, navigate to the template, and click **Open**.

13. Click **Save**.
