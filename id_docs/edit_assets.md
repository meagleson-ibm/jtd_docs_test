# Editing Assets

You can edit existing assets on the **Asset Management** tab.

1.  On the **Configuration Management** page, select the **Asset Management** tab.

2.  In the table, select the **More** menu next to the asset you want to update, and click **Edit**.

3.  On the **Attributes** page, you can update any of the following fields:

    -   **Asset Name**
    -   **Vendor**
    -   **Serial Number**
    -   **Model**
    -   **Vendor**
    -   **Asset Type**
    -   **Terminal Type**
    -   **Parent Asset Name**
    -   **Comments**
4.  On the **Aspects** page, you can upload aspects from a JSON file.

5.  On the **Attachments** page, you can upload attachments to the asset..

6.  Click **Save**.


On the **Asset Management** tab, you can also click the **More** menu next to an asset to **Archive**, **Copy**, or **Delete** the asset, or **Download** it as a .csv file for reporting purposes.

**Note:** You cannot delete an asset that is used in a Test Definition or Test Plan.
