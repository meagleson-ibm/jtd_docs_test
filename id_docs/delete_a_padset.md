# Delete a Padset

**Note:** Only Project Administrators can create, assign, edit, upload/download, or delete Padsets. Released and archived Padsets cannot be deleted.

1.  Click your profile icon, then select **Administration configuration**.

2.  On the **Padset** tab, click the **Check Box** to the left of one or more Padsets.

3.  Click the **Delete** button that appears.

4.  Click **Delete** to delete the Padset. Note that once deleted, a Padset cannot be restored.
