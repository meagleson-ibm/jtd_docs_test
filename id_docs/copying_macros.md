# Copying Macros

Macro Owners can duplicate \(copy\) macros that they created.

Macro owners can copy \(duplicate\) macros that they created in projects.

1.  Select the **Project** in which you want to copy your Macro.

    The Project page opens and displays the **Macro View** tab.

2.  Click the **Checkbox** next to the name of the macro or macros to be duplicated.

3.  Click **More** in the Blue Menu Bar to open a drop down menu.

4.  Click **Duplicate** in the drop down menu.

    The Copy Selected Modal opens.

5.  Click the **Minus \(-\)** and **Add \(+\)** icon to enter the number of copies you want.

6.  Click **Copy**.

    A system notification confirms that the selected number of each macro have been created. The newly created Macros are added to the Macro list and the copied Macros are named Macroname\_copy1, Macroname\_copy2, and so on for each macro. These copies are functionally identical to the original macro, and can be moved, edited, copied, cloned, etc. as any normal macro can. The only difference is that the copied macros will show copy in the createdUsing field.
