# Restoring a test definition

If you need to use a Test Definition that has been archived, you can restore it from the Inactive tab.

1.  On the Test Definition page, select **Inactive**.

2.  In the Test Definitions table, select one or more Test Definitions that you want to restore, and select **Restore**.

3.  Click **Restore** on the verification window.

    The Test Definition is returned to the Active tab and can be added to a Test Plan.
