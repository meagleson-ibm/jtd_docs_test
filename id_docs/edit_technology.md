# Editing a Technology

Project Administrators can edit Technologies on the **Technology** tab.

**Note:** Only Project Administrators can create, edit, or delete Technologies.

You cannot edit the **Technology Name** or **Status** for any Technology that is associated with one or more Projects.

1.  Click your profile icon, then select **Administration configuration**.

2.  On the **Technology** tab, select **Edit** from the **Actions** list for the Technology you want to edit.

3.  Type a new **Technology Name**.

4.  Type a new **Description** for the Technology.

5.  Select a new **Technology Owner** from the list of users.

6.  Select the **Status** to be Active or Inactive.

7.  Click **Save**.
