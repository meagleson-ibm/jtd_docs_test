# Deleting a Test Definition

You can delete an existing Test Definition and TPL file on the Test Definition page of the Intelligent Test app.

To navigate to the Test Definition page:

-   From the Intelligent Design app, click the **Switcher** icon and select **Intelligent Test**.
-   From the Test Plan page, click **Test Definition** from the navigation menu.

**Note:** Only Testers can create, edit, delete or upload Test Definitions.

1.  On the **Test Definition** page, select one or more Test Definitions and click **Delete**.

2.  On the confirmation dialog box, click **Delete** again.
