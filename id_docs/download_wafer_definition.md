# Download a Wafer Definition

Downloading a wafer definition allows a user to save a copy for backup or to use for creating other Wafer Definitions..

**Note:** Only users who are on teams assigned to the project that is referenced in a Wafer Definition can view, edit, delete, or download that Wafer Definition.

To navigate to the Wafer Management page:

-   From the Intelligent Design app, click the **Switcher** icon and select **Intelligent Test**. On the left side of the Intelligent Test page, click **Wafer Management**. The Wafer Management page opens.

1.  On the Wafer Management page, click **Hamburger Icon** for a given wafer definition and click **Download**.

2.  A dialogue opens, allowing the user to save the wafer definition as a JSON file. Click **Save** to save the wafer definition to the local filesystem.
