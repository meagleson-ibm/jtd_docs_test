# Access Requirements

Before a user can gain access to the Intelligent Design \(ID\) App, a user must fulfill the following conditions:

-   Access to an IBM® issued computer with the approved IBM configuration.
-   That computer must have the configuration to connect to the network accessible to this service.
-   One of the following browsers:
    -   Firefox
    -   Chrome
    -   Edge
