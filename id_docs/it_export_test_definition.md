# Exporting Test Definitions

You can export Test Definitions on the Test Definition page to a .csv formatted file.

To navigate to the Test Definition page:

-   From the Intelligent Design app, click the **Switcher** icon and select **Intelligent Test**. The Test Plan page opens.

1.  Click **Test Definition** in the navigation pane to open the Test Definition page.

2.  Select one or more Test Definitions in the table, and click **Export**.

    The Test Definitions are saved to your Downloads folder in a .csv file that includes the following columns:

    -   TestDefinitionName
    -   TestDefinitionDescription
    -   Type
    -   Subtype
    -   GroupTerminals
    -   EquipmentType
    -   MeasurementLibrary
    -   Algorithm
    -   InputParams
    -   OutputParams
    -   DeviceParams
    **Tip:** You can modify this Test Definition .csv file offline and use it to [Upload Bulk Test Definition](upload_test_definitions.md).
