# Projects page

To view the Status and Design Lifecycle dashboard, click the **Projects** icon in the navigation pane.

![Dashboard link](_images/dashboard_link.jpg)

On the Projects page, clicking any of these feature tabs give you different views of the information in the app.

-   **All Projects**
-   **Recently Viewed**
-   **Favorites**

The following icons display on the ID application menu.

![Light mode](_images/light_mode.jpg)![Dark mode](_images/dark_mode.jpg)![System mode](_images/system_mode.jpg)**Light/Dark Mode** Click to toggle between light and dark mode or system setting.

![Notifications](_images/notifications.jpg) **Notifications**

![Switcher](_images/settings.jpg) **Switcher** Click the **Switcher** icon to move between the Intelligent Design, Intelligent Test, and Post Test Calculation modes.

**Note:** The Intelligent Test mode is visible to users with either the Tester or Project Administrator roles.

![User preferences](_images/user_prefs.jpg) **User** Click the **User** icon to access the Admin Functions. Only users with admin user privileges can view this content.
