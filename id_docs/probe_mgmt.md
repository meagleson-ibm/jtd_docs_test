# Probe Management

Create and manage Probes, which are physical probe interfaces used in testing.

**Note:** Only Testers and Test Engineer Administrators can create, update, or delete Equipment, Probes, and Assets.

-   **[Adding a probe card](../id_docs/probe_card_create.md)**  
Use the **Probe Management** tab to create and manage Probes.
-   **[Editing Probe data](../id_docs/edit_probe.md)**  
You can edit existing Probe cards on the **Probe Management** tab.
