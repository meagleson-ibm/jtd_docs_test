# Creating a Die Map

You can create a Die Map on the Wafer Definition detail page of the Intelligent Test app.

To navigate to Die Management:

-   From the Intelligent Design app, click the **Switcher** icon and select **Intelligent Test**. On the left side of the Intelligent Test page, click **Wafer Management**. The Wafer Management page opens. Click any existing Wafer Definition to view the Wafer Definition in detail.

1.  When viewing a Wafer Definition in detail, click **Create Die map**.

2.  On the Create a die map page, the map can be defined via JSON upload, or manual definition.

3.  To create the map via upload, click **Upload**. Select a properly formatted die map JSON file and click open. The die map will be automatically filled in with details from the JSON files, but these can still be edited.

4.  To create the wafer by manual entry, enter a **Name** for the map, along with a description. After these have been done, click **Next**.

5.  On the Die map layout page, the active die can be selected by checking the box by their listing in the Die Map chart, or by clicking the die on the **Wafer Map**. When a die is selected, it will be highlighted on both the chart and the map.

6.  After selecting the active die to make the map, clicking **Create** creates the new Die map and navigates to the Wafer Definition detail page.

7.  On the Wafer Definition detail page, the created die Map will appear at the bottom. It can be seen in **Table View**, and clicking **Grid View** displays the die maps side by side grid. Clicking **View Details** brings up a more detailed view. Clicking the **arrows** at the bottom of this view allows the user to quickly navigate between and compare die maps. Clicking **X** closes the window and returns to the Wafer Definition detail page.
