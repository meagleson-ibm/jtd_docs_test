# Supported functions

Any function in the `.NET` Math library can be used.

[https://learn.microsoft.com/en-us/dotnet/api/system.math](https://learn.microsoft.com/en-us/dotnet/api/system.math)

Only functions that support double as an input can be used, as parameters looked up are doubles.

5.  `Exp –`
6.  `Cos –`
7.  `Cosh –`
8.  `Log –`
9.  `Ln –`
10. `Sin –`
11. `Sinh –`
12. `Sqrt –`
13. `Tanh –`
14. `Tan –`
15. `^ – Power`
