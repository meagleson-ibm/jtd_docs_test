# Application elements

The following topics describe different navigation and control elements that appear throughout the application. Use this section to learn how to use these elements to their fullest potential.

-   **[Status and Design Lifecycle Dashboard](../id_docs/status_design_dashboard.md)**  
The Status and Design Lifecycle dashboard is the default landing page when logging into **Intelligent Design**.
-   **[Projects page](../id_docs/id_ug_landing_page.md)**  
To view the Status and Design Lifecycle dashboard, click the **Projects** icon in the navigation pane.
-   **[Tables](../id_docs/id_ug_tables_container.md)**  
In the Intelligent Design application, tables are used to present data and results uniformly.
-   **[Search - General and Wildcard](../id_docs/wildcard_search.md)**  
The Search function is available throughout the ID application.
