# Restoring a test plan

If you need to use a Test Plan that has been archived, you can restore it from the Inactive tab.

**Note:** Only Test Engineer Administrators and Testers can create, edit, delete, export, import, upload, or archive Test Plans.

**Note:** Users who are on teams that are assigned to the project that is referenced in a Test Plan are the only ones who can view, edit, delete, export, import, or archive the Test Plan.

1.  **Note:** Only Test Engineer Administrators and Testers can create, edit, delete, export, import, upload, or archive Test Plans.

    On the Test Plan page, select **Inactive**.

2.  In the Test Plans table, select one or more Test Plans that you want to restore, and select **Restore**.

3.  Click **Restore** on the verification window.

    The Test Plan is returned to the Active tab and can be used in Test Bench.
