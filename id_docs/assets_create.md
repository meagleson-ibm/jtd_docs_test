# Creating an Asset

Use the **Asset Management** tab to create and manage Assets.

1.  On the **Configuration Management** page, select the **Asset Management** tab.

2.  Click **Create asset**.

3.  Type a unique **Asset Name**, **Location**, **Serial Number**, **Model**, and **Vendor**.

4.  Select the **Asset Type**.

5.  Enter the **Terminal Type** and **Comments**, and select the **Parent Asset Name**.

6.  Click **Next**.

7.  Click the **Upload** icon to add probe aspects from a JSON file.

8.  Click **Next**.

9.  Click **Upload** to add attachments to the asset.

10. Click **Create**.
