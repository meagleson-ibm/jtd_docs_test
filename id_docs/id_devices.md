# Devices

A Device is a subsection of a Macro, referring to a specific area that makes up the Macro.

Device in Intelligent Design refers to a core technology area within a macro layout. There can be up to 50 devices per macro, depending on the size and wiring of each. Each Device in Intelligent Design represents a Device Under Test \(DUT\) in the layout and contains the parametric specifications if designed through automation. Devices can be mapped to specific pad assignments if electrical testing is needed.

When viewing a Project, click on the **Design View** tab to see a the list of devices for that Project.

**Note:** If the value of **ILT3D** is set to **Both**, the Device displays both Frontside and Grindside pad-to-terminal mappings side by side.
