# User roles

Users of the Intelligent Design application are assigned a user role. Different actions are available to each of the user roles.

-   **Project Administrator**

    A Project Administrator has full access to all features in the ID application. They can create, edit, and delete Technologies, Projects, Macros, Groups Padsets, and Devices.


-   **Macro Owner**

    A Macro Owner cannot create or edit Technologies or Projects. They can create, edit and delete Macros and Groups.


-   **Designer**

    A Designer cannot create or edit Technologies or Projects. They can create, edit and delete Macros and Groups.


-   **Tester**

    In the Intelligent Design application, a Tester cannot create or edit Macros but has limited permissions to create and use Groups.

    In the Intelligent Test application, a tester can create test plans and test definitions and submit those test plans to TestBench


-   **Test Engineer Administrator**

    In the Intelligent Design application, a Test Engineering Administrator cannot create or edit Macros but has limited permissions to create and use Groups.

    In the Intelligent Test application, a Test Engineering Administrator can create test plans and test definitions and submit those test plans to TestBench.

    In the Intelligent Test application, a Test Engineering Administrator is the only role that can create and edit wafer definitions.


-   **PTC Admin**

    A PTC Admin can add, edit and delete Lot disposition rules in the Post Test Calculation application.
