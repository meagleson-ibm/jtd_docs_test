# Intelligent Design Introduction

The ID product is a software system process that enhances and streamlines the manufacture of semiconductor chips. The ID system is agile and gives you the tools to design, create, and monitor a manufacturing and testing process that supports your goals for your semiconductor manufacturing process. When you create your fabrication solutions, you can monitor and alter your design and testing process and use that process to meet your manufacturing goals.

ID's two companion modules are Intelligent Test \(IT\) and TestBench \(TB\). The IT module provides testers with the tools to define **Test Definitions** and **Test Plans**. The TB module provides testers with tools to customize each test plan submitted to TB, and returns test results testers in IT as those test plans execute.

This User Guide explains how to understand and use each of the ID components. The Intelligent Test \(IT\) section of the user guide explains how to configure test definitions and test plans for test execution in TB.

|Intelligent Design Tools|Description|
|------------------------|-----------|
|Technology|A technology is a group of tests sites. ID Administrators define technologies for each testing instance.|
|Projects|After technologies are defined, you can then create a Project within that group of sites.|
|Macros|Within projects, you can then define Macros. Macros are separate sections of on semiconductor chips. You can design how to test the chips by using parameters that you define on the Devices.|
|Devices|Devices are the core technology area in a macro layout. You can assign electrical and other testing on devices.|
|Padsets|Padsets are on Devices, and each padset is designed for a specific set of electrical tests.|
|Intelligent Test|Intelligent Test \(IT\) is a companion module within the ID application. The IT module provides testers with the tools to define **Test Definitions** and **Test Plans**.|
