# Editing Equipment data

You can edit existing Equipment data on the **Algorithm Management** tab.

1.  On the **Configuration Management** page, select the **Algorithm Management** tab.

2.  In the table, select the **More** menu next to the Equipment you want to update, and click **Edit**.

3.  On the **Equipment Management** tab, you can update the **Equipment Name**, **Vendor**, **Type**, **Test Script Type**, **Model**, or **Description**.

4.  On the **Measurement Library Managment** tab, you can add or delete measurement libraries.

    **Restriction:**

    -   Individual algorithms cannot be edited or deleted in the UI.
    -   Old algorithms are archived to maintain references.
5.  On the **Probe Aspect Template**, you can upload or delete a probe aspect template.

6.  Click **Save**.
