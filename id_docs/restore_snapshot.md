# Restoring a Macro from a snapshot

If you previously created a snapshot of a Macro, you can restore the Macro, including all of its Devices and Padsets, to the exact state it was in at the point in time that you took the snapshot.

1.  On the **Macro View** tab, select the ellipsis **Options** icon next to the Macro in the table that you want to restore, then select **Snapshot**.

    A list of any existing snapshots for the Macro is displayed.

2.  Select the **Options** icon next to the snapshot you want to restore, and click **Restore**.
