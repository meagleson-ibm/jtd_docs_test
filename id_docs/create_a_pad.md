# Creating a Pad

A Pad can be added to a Device in Intelligent Design either during **Device creation**, or when editing a Device on the **Device Details** dialogue. The procedure is the same in both places.

1.  Click **Add Item** to create a Pad.

2.  Assign a **Number** to the pad. The number can be entered manually or adjusted via the **+ and -** buttons.

3.  Select a **Terminal** type for the pad. The type can be source, drain, gate, bc, etc.

4.  If the value of **ILT3D** is set to **Both**, assign a Number to the grindside pad mapping. The number can be entered manually or adjusted via the + and - buttons.
