# Deleting a Project

Project Administrators can delete Projects on the **All Projects** tab.

**Note:** Only Project Administrators can create, edit, or delete Projects. Project Administrators cannot delete a Project that is associated with one or more Macros. Project Administrators cannot delete a project's **Purpose** field if that purpose field is contained in a macro within that project.

1.  On the **All Projects** tab, select **Delete** from the **Actions** list for the Project you want to delete.

    **Note:** If a Project Administrator attempts to delete a Project's and the Project's **Purpose** field is used in a macro within the project, the system displays a warning and blocks the deletion. **You are attempting to remove purpose values that are currently being used in one or more macros. Please update the affected macros before deleting this Purpose value**.

2.  Click **Delete** to confirm.
