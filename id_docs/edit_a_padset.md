# Edit a Padset

Editing Padsets encompasses two distinct ideas- Changing the Padset's status, and using the edit option to change its aspects.

**Note:** Only Project Administrators can create, assign, edit, upload/download, or delete Padsets

.

1.  Click your profile icon, then select **Administration configuration**.

2.  On the **Padset** tab, click the **Hamburger Icon** and select Change Status.

3.  On the following dialogue, select a new **Padset status**. A Padset can be in created, released, or archived status. A created Padset can be made released or archived. A released Padset can be set to archived.

4.  Click **Save** to update the Padset status.

5.  **Note:** A Padset must be set to released status to be made available for association with a Project. Only an Administrator may associated a Padset with a Project.

    To edit a Padset, click the **More** icon next to the Padset, and select Edit to open the Edit Padset window.

6.  On the **Attributes** tab, you can edit the Padset's **Name**, **Technology**, and **Description**.

    **Note:** Each Padset can be associated with exactly one Technology. Existing Padsets without a Technology assigned must be retroactively assigned to a Technology before use.

7.  Click **Save** to confirm any unsaved changes. This does not close the Edit Padset window.

8.  On the **Aspects** tab, Click the **Pencil Icon** or the value of any Aspects you want to modify. When finished editing a value, click the **Check** to confirm the changes. Click **Save** to confirm any unsaved changes. This does not close the Edit Padset window.
