# Copying a Test Definition

You can copy any existing Test Definition on the Test Definition page, modify it, and save it as a new Test Definition.

To navigate to the Test Definition page:

-   From the Intelligent Design app, click the **Switcher** icon and select **Intelligent Test**.
-   From the Test Plan page, click **Test Definition** from the navigation menu.

**Note:** Only Testers can create, edit, delete, or upload Test Definitions. Test Definitions that are used in a Test Plan cannot be edited or deleted.

1.  On the Test Definition page, select the **Options** icon next to a Test Definition, and click **Copy**.

2.  Update the **Name** for the new Test Definition.

3.  Modify any of the following attributes:

    -   **Description**
    -   **iltType**
    -   **iltSubTypes**
    -   **Specifications**
    -   **Equipment**
    -   **Measurement Library**
    -   **Algorithm**
    -   **Input Aspects**
    -   **Output Aspects**
    -   **Device Parameters**
    **Note:** If you change the **iltType**, all four **iltSubTypes** are reset, and a warning message appears. You must also update the iltSubTypes.

4.  Click **Create**.

    **Note:** After you create the Test Definition, you cannot further edit it. The Test Definition is saved, but is not editable.
