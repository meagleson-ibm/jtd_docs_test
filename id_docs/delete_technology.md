# Deleting a Technology

Project Administrators can delete Technologies that are not associated with any Macros.

**Note:** Only Project Administrators can create, edit, or delete Technologies.

You cannot delete a Technology that is associated with one or more Macros.

1.  Click your profile icon, then select **Administration configuration**.

2.  On the **Technology** tab, select **Delete** from the **Actions** list for the Technology you want to delete.

3.  Click **Delete** to confirm.
