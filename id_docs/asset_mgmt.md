# Asset Management

Create and manage Assets, which are physical infrastructure components, such as test cells, instruments, probe cards, or terminals.

There are 4 types of Assets:

-   **Test Cells**

    Primary asset

-   **Instruments**

    Connected to Test Cells

-   **Instrument Terminals**

    Connected to Instruments

-   **Probe Cards**

    Connected to Test Cells


**Note:** Only Testers and Test Engineer Administrators can create, update, or delete Equipment, Probes, and Assets.

-   **[Creating an Asset](../id_docs/assets_create.md)**  
Use the **Asset Management** tab to create and manage Assets.
-   **[Editing Assets](../id_docs/edit_assets.md)**  
You can edit existing assets on the **Asset Management** tab.
-   **[Archiving and restoring Assets](../id_docs/archive_assets.md)**  
When an asset is outdated or no longer used, you can archive it to remove it from your daily view.
