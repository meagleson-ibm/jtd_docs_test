# Edit a Die Map

Editing a die map allows a user to adjust and correct its details as needed.

To navigate to Die Management:

-   From the Intelligent Design app, click the **Switcher** icon and select **Intelligent Test**. On the left side of the Intelligent Test page, click **Wafer Management**. The Wafer Management page opens. Click any existing Wafer Definition to view the Wafer Definition in detail.

1.  **Remember:** Die Maps can only be edited when using the Table View.

    When viewing a Wafer Definition in detail, click the **hamburger icon** and select **Edit** to bring up the Edit die map page. The page has two tabs, Die map Attributes and Die map layout.

2.  On the Die map Attributes tab, the map's name and description can be changed.

3.  On the Die map layout page, the active die can be selected by checking the box by their listing in the Die Map chart, or by clicking the die on the **Wafer Map**. When a die is selected, it will be highlighted on both the chart and the map.

4.  **Note:** Navigating away from the Die map layout tab without saving will void any changes made to the die map. The **Save** button is only clickable when all required fields have valid data.

    Click **Save** to save any change made, or **Cancel** to discard them. Either selection navigates to the Wafer Definition detail page.
