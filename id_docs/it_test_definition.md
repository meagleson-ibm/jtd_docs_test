# Test Definition

Test Definition is used to create a Test that would later be used in a Test Plan. Here you can specify the test and the details surrounding the test to be used in the Test Plan.

-   **[Creating a Test Definition](../id_docs/it_create_test_def.md)**  
You can create a Test Definition on the Test Definition page of the Intelligent Test app.
-   **[Deleting a Test Definition](../id_docs/it_delete_test_def.md)**  
You can delete an existing Test Definition and TPL file on the Test Definition page of the Intelligent Test app.
-   **[Exporting Test Definitions](../id_docs/it_export_test_definition.md)**  
You can export Test Definitions on the Test Definition page to a .csv formatted file.
-   **[Upload Bulk Test Definition](../id_docs/upload_test_definitions.md)**  
You can now upload Bulk Test Definitions on the Test Definition page by uploading a properly formatted .csv file that contains the required Test Definition fields.
-   **[Copying a Test Definition](../id_docs/it_copy_test_def.md)**  
You can copy any existing Test Definition on the Test Definition page, modify it, and save it as a new Test Definition.
-   **[Support for \(Sweeps\) Arrays of input values and results](../id_docs/sweeps_arrays.md)**  
This feature supports the ability to define parameter sweeps within a single Test Definition, eliminating the need to manually create multiple test cases. This functionality enables automation to dynamically generate a series of test instances based on input value variations.
-   **[Archiving a Test Definition](../id_docs/it_archive_test_def.md)**  
When a Test Definition is outdated or no longer used, you can archive it to remove it from your daily view.
