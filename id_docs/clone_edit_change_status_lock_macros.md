# Clone/Edit/Change Status/Lock Macros

Project Administrators, Macro owners and Designers can clone, change status, edit, and lock macros that they created.

Project Administrators, Macro owners and Designers can clone, edit, change status, and lock macros they create. In the Macro view table, each row displays an individual macro. At the end of each row, Project Administrators, Macro owners and Designers can click a vertical ellipsis to open a list of options: Clone, Edit, Change Status, and Lock.

For each Macro you want to impact, click the vertical ellipsis in that row and select one of the following options.

|Option|Description|
|------|-----------|
|Clone|Click the **Checkbox** next to the name of the macro or macros to be duplicated. Click **More** in the Blue Menu Bar to open a drop down menu. Click **Duplicate** in the drop down menu to open the Clone Macro Modal. Click the **Minus \(-\)** and **Add \(+\)** icon to enter the number of clones you want. Click **Clone**. A system notification will either confirm successful creation or alert if the clone could not be created. The cloned Macro or Macros are added to the Macro list and named Macroname\_c1, Macroname\_c2, etc.|
|Change Status|Clicking **Change Status** opens the Change Status modal. Use the drop-down arrow to change the Request Complete Status to Update Required. Click **Save**. A system notification asks for confirmation of the status change. Click **Save Changes**. A system notification confirms that the design status was updated.|
|Edit|Clicking **Edit** opens the Edit Macro modal. Edit can be made to Attributes, Aspects, and Attachments. As you make your changes, the Details side bar shows a summary of those changes. Click **Save**. A system notification confirms that the changes were saved. Selecting the Macro opens the Details side bar where you can view the last modified date.|
|Lock/Unlock|Click **Lock**. The Lock modal opens and asks for Lock confirmation and notifies the Macro Owner that locking the Macro disables editing capabilities. Click **Lock**. A system notification confirms that the Macro is locked. The lock status displays in the Details side bar. To unlock a locked macro, click **Unlock**.**Tip:** You can lock or unlock multiple macros at the same time by selecting them in the table and then selecting **Lock** or **Unlock** from the drop-down menu.

|

## Macro status options

|Status|Who can set this status?|Type|Description|
|------|------------------------|----|-----------|
|Request Incomplete|Macro Owner / Project Admin|Automatic|Macro is created. Macro owner is still specifying Macro specs.|
|Request Complete|Macro Owner / Project Admin|Manual|Macro specifications are completed.|
|Update Required|Designer / Project Admin|Manual|Specs are unclear and need updates.|
|Request Updated|Macro Owner / Project Admin|Manual|Macro Owner made needed updates and is resending for further work to designer.|
|Layout In Progress|Designer / Project Admin|Manual|Layout work \(in cadence\) is ongoing.|
|Layout Complete|Designer / Project Admin|Manual|Layout work is complete.|
|Layout Verified|Macro Owner / Project Admin|Manual|Macro Owner verified the layout and approves the end result.|
|Awaiting Waiver|Macro Owner / Project Admin|Manual|All needed verifications are completed and waivers have been submitted.|
|Ready for Assembly|Macro Owner / Project Admin|Manual|All waivers are completed.|
