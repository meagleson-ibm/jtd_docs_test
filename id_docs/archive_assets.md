# Archiving and restoring Assets

When an asset is outdated or no longer used, you can archive it to remove it from your daily view.

Archived assets are moved to the **Inactive** tab on the **Asset Management** page. Archived assets are excluded from the Test Plan and Test Definition **Add Asset** section, but remain searchable and retrievable. You can restore archived assets to the **Active** list if needed.

1.  On the **Configuration Management** page, select the **Asset Management** tab.

2.  In the table, select the **More** menu next to the asset you want to update, and click **Archive**.

3.  Confirm the action by clicking **Archive** on the confirmation window.

    The asset is moved to the **Inactive** tab.

4.  To restore an asset, select the **More** menu next to the asset on the **Inactive** tab, and click **Restore**.
