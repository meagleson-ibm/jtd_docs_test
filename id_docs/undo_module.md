# Undo Modules

INTED-3138

Once a macro is converted into modules or grouped, users cannot undo this action. If they change their mind or need to correct a mistake, there is no way to remove the modules or group and revert to the original macro\(s\). Proposed Improvement:Users should be able to undo the module conversion or group creation, restoring the macro\(s\) to the original state.

Modules: Users should be able to select an option to "Undo Module Conversion" User should be able to confirm the action Child Modules should be removed, parent macro should be reverted to independent macro \(core\)
