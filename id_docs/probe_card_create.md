# Adding a probe card

Use the **Probe Management** tab to create and manage Probes.

Equipment must exist in [Algorithm Management](algorithm_mgmt.md) before you can add a probe card.

1.  On the **Configuration Management** page, select the **Probe Management** tab.

2.  Click **Add a probe card**.

3.  Type a unique **Probe Name**, **Vendor**, **Model**, **PadPitchX**, and **PadPitchY**.

4.  Select the **Equipment** and **Layout**.

5.  Enter the **Min Temperature**, **Max Temperature**, and **Material type**.

6.  Click **Next**.

7.  Click **Add item** to manually add probe aspect key-value pairs, or click **Upload JSON** to add probe aspects from a JSON file.

8.  Click **Create**.
