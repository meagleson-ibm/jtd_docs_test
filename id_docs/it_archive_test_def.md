# Archiving a Test Definition

When a Test Definition is outdated or no longer used, you can archive it to remove it from your daily view.

Archived test definitions are moved to the Inactive tab on the Test Definition page. Archived test definitions are excluded from the Test Plan **Add Device** section, but remain searchable and retrievable. You can restore archived Test Definitions to the Active list if needed.

1.  In the Test Definition table, select one or more Test Definitions that you want to archive, and click **Archive**.

2.  Click **Archive** on the verification window.


-   **[Restoring a test definition](../id_docs/restore_test_def.md)**  
If you need to use a Test Definition that has been archived, you can restore it from the Inactive tab.
