# Editing an Existing Report

ABI users can now edit their own reports using the editing options of **Export**, **Import**, **Copy**, and **Paste** for individual fields within a report. The **Import** function allows users to import .csv and .xlsx and **Export**, **Copy**, and **Paste** functions support the .csv format.

**Report Editing Rules**

-   Users can edit only a report that they own.
-   Users who have Share \(View\) privilege with a report can use the **Copy** function to copy individual fields into a new report that they own.
-   The **Copy** function copies the filter language into a copy buffer. Filters within the buffer can then be pasted elsewhere. The **Export** function downloads the filter languages as a .csv file.

1.  Click the **Reports** tab on the ABILanding page and then click your **Report** to open it.

2.  Click the **Edit \(pencil\)** icon. Select the tab for each individual field you want to manipulate and set its status to **In** and scroll to select the field attribute. Click the **Up Down** arrows icon and select an action from the drop-down menu: **Import**, **Export**, **Copy**, or **Paste**.

    ![Manipulating Individual Fields Editing a Report](images/abi_edit_individual_report_%20fields_1.jpg "Manipulating Individual Fields Editing a Report ")

    **Note:** Depending on a user's choice of actions, the following happens.

    -   Clicking **Import** opens up a window where the user selects a field value to import in .xlsx format
    -   Clicking **Export** downloads the field selection as a .csv file
    -   Clicking **Copy** copies the field value to the buffer
    -   Clicking **Paste** opens an ABI permission dialog. Click **Allow** and the field value is pasted to the buffer.
