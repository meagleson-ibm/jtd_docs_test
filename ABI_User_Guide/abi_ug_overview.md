# Overview

This User Guide provides an introduction to the Analytics and Business Intelligence \(ABI\) UI application. This User Guide shows you how to create and log in to your ABI account to navigate the application, and how to access information from the Data Warehouse \(Data Warehouse\).

The documentation includes information about:

-   Access Requirements
-   Getting Access
-   Logging In and Out
-   General Navigation elements
-   User Preferences
-   Reports
-   Groups
-   Portfolios
-   Charts
-   Troubleshooting
-   Administrative Functions
-   Glossary

-   **[Access Requirements](../ABI_User_Guide/abi_ug_access_req.md)**  
Before a user can gain access to ABI, they must fulfill the following conditions:
-   **[Getting access permission](../ABI_User_Guide/abi_ug_access_perm.md)**  
To access ABI, users must follow the designated protocol established by their company.
-   **[User Roles](../ABI_User_Guide/user_roles.md)**  
Users of the ABI application are assigned one or more of four different user roles. Different actions are available to each of the user roles.
-   **[Logging in](../ABI_User_Guide/abi_ug_log_in.md)**  
All ABI users must follow and complete the established protocols.
-   **[Privacy notice](../ABI_User_Guide/abi_ug_privacy.md)**  
The first time you access the ABI application, you are presented with a privacy statement.
-   **[Logging out](../ABI_User_Guide/abi_ui_logout.md)**  
Users are automatically logged out after several minutes of inactivity.
