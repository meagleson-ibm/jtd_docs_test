# Error and User Action Messages

In the ABI application if an error occurs during normal operation, an error banner opens and notes the error.

Error message **Authentication Lapsed** indicates that the user’s login session has expired. Select **Login** to re-authenticate and continue using the application.

![Error Banner that displays when system requires an ABI user to re-authenticate.](images/Error_Authentication_Login_800_49.png "Authentication Error")

Error message **Error Fetching from Server** indicates that a connection to the server has failed. Close this error and check your connection.

![Error Banner that displays when system encounters an error fetching from the server.](images/Error_Fetching_From_Server_800_48.png "Error Fetching from Server Banner")

Error message **Creating/Updating WIP Report** indicates that the WIP Report cannot be created or updated.

![Error Banner that displays when system cannot Create or Update a WIP Report](images/Error_Error_Creating_WIP_Report_800_49.png "Error Creating or Updating WIP
Report")

Error message **Error Loading Lot Details** displays when a Lot does not exist in the database.

![Error displays when a Lot cannot be found in the data base.](images/Error_Error_Loading_Lot_Details.jpg "Error Loading Lot Details -")

Error message **Duplicate Oper Information for Wafer Showing Only New Newest Claim** displays when duplicate wafer information exists. The application displays only the newest claims.

![Error Duplicate Oper Information for Wafers Showing Only the Newest Claim](images/Error_Duplicate_OperInfo_Showing_OnlyNewestClaim.jpg "Error Duplicate Oper Information for Wafers
Showing Only the Newest Claim")

Error message **Create Report: No context found for report creation. Navigated to Dashboard.** displays when a user tries to create a report and the application cannot locate the report context to create a report.

![The systems returns to the dashboard when it cannot locate context for report creation.](images/Error_No_Context_Found_Dashboard.png "No context found for
Report Creation. Navigated to Dashboard.")

Error message **Application Update Required. Please refresh the page ASAP** displays when an immediate refresh of the ABI application is required.

![Application Update Required: Please refresh ASAP](images/Error_Application_Update_Required.jpg "Application Update Required: Please refresh ASAP")

-   **[Admin Functions](../ABI_User_Guide/abi_ug_admin_functions.md)**  
Administrative Functions in the ABI application give administrators access to view and monitor the ABI application functions and user activities within the application. Administrators can see application email failures, user activity, historical administrative actions, and inactive ABI assets. Administrators can also compose and send informational and warning notifications.
