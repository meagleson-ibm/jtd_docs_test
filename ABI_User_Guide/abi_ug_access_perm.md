# Getting access permission

To access ABI, users must follow the designated protocol established by their company.

The IBM's designated protocol to access ABI is that users must added to the appropriate BlueGroup. IBM users must contact the IBM lead \(Robert Halsted\) to request access.

All ABI users must have a valid IBM w3 ID.
