# Objects

Objects in ABI are entities, physical and virtual, required for the creation of functional silicon chips. Physical Objects can include elements like the Lot, Wafer, and manufacturing Equipment, while non physical Objects can include Product IDs, Routes, and Recipes.

**Tracking Objects**

In the ABI application, you can view and track any object, such as a Lot ID, by clicking the Lot ID and clicking **Track Object**. The tracked object is then added to the list of objects that display in the Object tab. The object remains tracked until you click **Untrack Object**.

**Exporting Object**

In the ABI application, you can export and download the following objects: **Lots**, **Wafers**, **Front Opening Unified Pods \(FOUPs\).**

-   **[Object Types](../ABI_User_Guide/abi_ug_ObjectTypes.md)**  

-   **[Exporting Objects](../ABI_User_Guide/exporting_object.md)**  
In the ABI application, you can export and download a list of objects from the following object categories: **Lots**, **Wafers**, and **Front Opening Unified Pods \(FOUPs\)**.
-   **[Navigating the Objects Tab](../ABI_User_Guide/abi_ug_object_tab.md)**  
The **Object** tab allows a user to keep track of the numerous object types used in the ABI application.
-   **[Lot view](../ABI_User_Guide/abi_ug_lot_view.md)**
