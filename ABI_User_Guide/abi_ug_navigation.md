# Application elements

The following topics describe different navigation and control elements that appear throughout the ABI application. Use this section to learn how to use these elements to their fullest potential. throughout the application. Use the following subtopics to learn how to use these elements to their fullest potential.

**Note:**

**Application Refresh**

From anywhere within the ABI application, use the keyboard shortcuts **Shift****&** **Reload** to automatically update the ABI Application. This action clears the browser cache.

**Navigation**

When navigating within the ABI application, refrain from using the **Browser Back** control. Use the breadcrumbs to browse within the application.

**Open Data in a New Window**

Use this short cut to view data in a new window for any data in an ABI table. For example, if you want to view data in a new window, position your cursor over the data and use **Ctrl + Shift + Click** to open that data in a new window. You can then toggle between the windows to view the data.

-   **[ABI Landing page](../ABI_User_Guide/abi_ug_landing_page.md)**  
When you log in to the ABI application, the ABIlanding page opens. It is the entry point into the ABI application. From the landing page, you can click the feature tabs to access different types of information from the Data Warehouse \(Data Warehouse\).
-   **[Tables](../ABI_User_Guide/abi_ug_tables_container.md)**  
In the ABIapplication, tables are used to present query results uniformly. All report types, Reports, Portfolios, Tracked, and Objects present query results in a table view.
-   **[Creating and Organizing with Folders](../ABI_User_Guide/abi_ug_folder_management_procedure.md)**  
On the ABILanding page, you can use folder management to organize your work flow to meet your needs.
-   **[View SQL](../ABI_User_Guide/abi_ug_view_sql.md)**  
Structured Query Language \(SQL\) is the programming language that is used to access and retrieve defined parameters from the Data Warehouse tables for ABI reports. The **View SQL** control in the ABI UI opens a modal that shows how the SQL command ran and gathered the requested information for WIP, Claim and PLY Reports, and Lot Lists.
-   **[Search bar](../ABI_User_Guide/abi_ug_search_bar.md)**  
The Search Bars are useful tools for ABI users. Each search bar searches a designated area within the application. Search types are Global, Data Grid, and Column Search.
-   **[Global User Preferences](../ABI_User_Guide/abi_ug_preferences.md)**  
Global User Preferences in the ABI application are preferences that users can select to expand or restrict their access in the application. There are several types of **Global User Preferences**: **General**, **Tables**, and **Charts**.
