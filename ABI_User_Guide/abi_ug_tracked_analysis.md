# Tracked

ABI allows a user to manage sets of common objects and quickly access them via tracking. You can track most objects in the ABI application by clicking **Track Object** on the object's details page which allows you to manage sets of common objects for quick access. Objects you select to track appear on the Tracked tab in the ABI UI.

You can track any of the following object types in the Tracked tab:

-   Lots
-   Wafers
-   FOUPs
-   Equipment IDs
-   PD IDs
-   Product IDs
-   Mainpd IDs
-   Cassettes
-   Ply Tool Recipes
-   Recipes
-   Logical Recipes

For more information on Objects and the different types of objects, see [Objects](abi_ug_objects.md).
