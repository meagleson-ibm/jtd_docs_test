# Filter Sets

Filter Sets are sets of filter settings that are created and stored per report but are savable, editable, and transferable between reports in ABI.

Filter Sets exist to make the process of sorting and filtering the data within a report easier, reproducible, and transferable. Filter sets exist at the level of an individual report, and are created, edited, and deleted per report, though they can be copied to other reports.

**Note:** Filter Sets now support **A Case Insensitive Contains Operation**that links directly to the database that supports wildcarding. See [Search bar](abi_ug_search_bar.md).
