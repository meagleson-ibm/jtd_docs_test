# Creating a Portfolio - Within an ABI Asset

Using Portfolios, you can categorize and organize all of your ABI assets. Assets within the ABI application include reports, charts, objects, and tracked objects. In a Portfolio, you can organize all your assets and as a Portfolio owner, share your portfolio and assets within the portfolio with other ABI users, and remove assets that you own using the **Edit** control. You can create and add to portfolios from within an ABI asset; a report, a chart, a tracked object, or an object.

ABI users can create new portfolios and add to existing portfolios from within Reports, Charts, Tracked Objects, and Objects that they own. These steps outline how to add to an existing portfolio or create a portfolio from within a report and the steps are similar for any ABI asset.

**Note:** If you place a private ABI asset into a portfolio and then share that portfolio with an ABI user, the private asset is not viewable to the shared ABI user. By default Portfolios are private, and only Asset Owners and ABI Admins can view private portfolios and assets.

In order for Portfolio assets to be visible to ABI users, Portfolio owners must set sharing options on both Portfolios **and** on each individual asset within the Portfolio.

Portfolios and the assets within them are not static - assets within Portfolios refresh when the original asset content refreshes. See Portfolios: [Portfolios](abi_ug_portfolios_overview.md).

1.  Click the Portfolio icon from within an ABI asset.

    ![Clicking the Portfolio Icon opens the Add To - Create Portfolio Modal](images/Portfolio_Add_to_Create_Within_Asset_1.jpg "Clicking the Portfolio Icon opens the Add-To and Create Portfolio
    Modal ")

2.  Select one of the following options to either add to an existing portfolio or create a new portfolio.

    -   Click one or multiple existing portfolios to add the ABI Asset \(report\) to an existing portfolio. Click **Add**. The ABI Asset is added to the selected portfolio. **OR**,

        ![Completing the Create or Add To a Portfolio Modal](images/Portfolio_Create_6_Add_to_PortStep_2.jpg "Completing the Add To or
        Create a New Portfolio Modal ")

    -   Click **Create New Portfolio** control. The **Create New Portfolio** modal opens.
    ![Complete the fields in the Create a New Portfolio Modal](images/Portfolio_Add_to_Create_Within_Asset_CreateNewP_3.jpg "Complete the fields in the Create a New Portfolio
    Modal")

3.  Complete the fields in the **Create New Portfolio** modal.

4.  Click **Create**. The portfolio is created in the chosen designated folder.

5.  Browse to the Portfolio tab on the ABI Landing Page to view the ABI asset in the existing portfolio you selected or in the new portfolio just created.
