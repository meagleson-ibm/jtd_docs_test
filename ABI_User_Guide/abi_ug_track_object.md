# Tracking an object

Click **Track Object** on the object's details page to track any object in the ABI application. Objects you select to track appear on the Tracked tab in the ABI UI.

1.  On any page in the ABI UI, click the ID of the object you want to track.

    **Example:** Click a Lot ID, Wafer ID, or PD ID in any table.

    This opens the object's details page.

2.  Click **Track Object** on the object's details page.

    The object now appears on the Tracked tab.

    **Tip:** To remove an object from the Tracked tab, click **Untrack Object** on the object's details page.
