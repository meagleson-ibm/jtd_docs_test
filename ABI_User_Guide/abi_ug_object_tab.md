# Navigating the Objects Tab

The **Object** tab allows a user to keep track of the numerous object types used in the ABI application.

1.  On any page in the ABI UI, click the **Object** tab, .

    The Object Tab loads.

2.  Click any of the **Object Types** depicted on the object tab.

    The Object Tab loads all recent entries of that Object Type.

3.  Click on the **ID** of an Object in that Object type.

    The Object details page loads. Each object type loads a different detail page with different relevant information and subtabs.
