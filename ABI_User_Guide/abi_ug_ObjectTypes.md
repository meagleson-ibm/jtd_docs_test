# Object Types

The object tab contains information on multiple object types. Each object is distinct, but can be related to or reference other objects and object types.

-   ****Lot****

    Lot Objects represent physical Lots of Wafers, typically 25 Wafers to a Lot.

-   ****Wafer****

    Wafer Objects represent physical silicon wafers, from which Chips are formed.

-   ****FOUP****

    FOUP Objects represent Front Opening Unified Pods, which are used to safely store and transport silicon wafers around a foundry.

-   ****Equipment****

    Equipment Objects represent other physical equipment around the foundry, such as etchers, test benches, and packagers.

-   **Durable**

    Durable objects define the equipment, recipe, and route for durable processes, including cleaning, measurement, and inspection.

-   ****PD ID****

    PD \(Process Definition\) ID objects represent non-physical processes definitions. Each one represents a process to perform on a wafer in the chip manufacture process.

-   ****Product ID****

    Product ID objects represent physical products created as part of the manufacturing process, including intermediary and finished products.

-   ****Route****

    Route objects represent specific paths through the Chip to be made during testing and manufacture.

-   ****PLY Tool Recipe****

    PLY \(Process Limited Yield\) Tool Recipe objects represent a combination of equipment and steps used to evaluate the yield of a given lot or lots.

-   ****Recipe****

    Recipe objects represent a combination of physical materials and procedures performed on materials to achieve a specific result.

-   ****Logical Recipe****

    Logical Recipe objects represent a combination of materials and procedures to achieve a specific effect or perform, a test regarding the logic circuits of a chip.

-   ****DC Spec****

    DC \(Data Collection\) Spec objects represent methods of collecting measurements and Metrology for analysis
