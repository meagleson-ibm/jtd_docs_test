# Access Requirements

Before a user can gain access to ABI, they must fulfill the following conditions:

-   Gain access to an IBM® issued computer with the approved IBM configuration.
-   Connect the approved computer to an IBM internal network, either physically at an IBM site or om the Cisco Secure Client.
-   Use one of the following approved browsers.
    -   Firefox
    -   Chrome
    -   Edge
