# Customizing Table Columns

Within the ABI application, ABI users can customize table columns within the ABI application using the **Manage Columns** feature. Advanced table column customization features are available for **Reports** only.

**Managing Columns in a Standard Shared Report**

When the ABI application generates a standard report, report columns display a standard report default view in the Draft, View Results, and Saved Report formats. All ABI users can customize report columns in the reports they create, edit, or view; however, only that individual ABI viewer can see their own customizations. The ABI viewer can also select the Revert to Defaults to return the customized report to its original standard default view. As with all reports, when changes are made, the report must be saved.

**Standard Shared Reports - Customizing Your Personal View**

If an ABI report owner saves and shares a report with standard columns, each ABI user with shared access who views the saved report sees the standard columns in the report. However, each individual ABI user with shared access to the standard column view can customize the columns in the table for their personal viewing. When an individual user changes the standard column view in the share report to a customized column view, only they have access to the customized view they create. The individual ABI user can click **Restore to Default** to restore the default to the standard report column view and discard their personalized view changes.

## Advanced Report Column Customization

An advanced option report owners can take is to globally customize columns in reports they own. When an owner globally customizes report columns, the owner is setting a new default for customized columns in the report. When report owners shares the globally customized report with other ABI users, recipients can still configure their own personal views. Configuring their own personal view does not alter the globally customized report, but clicking **Restore to Default** restores the report only to the globally customized view.

**Globally Customizing Report Columns**

Globally customizing report columns and sharing the report with a globally customized report view is available only for Reports. Use this procedure to globally customize and share a report with customized columns.

1.  Open a report that you own. Use the **Manage Columns** control to change the columns that display in the report. See [Configuring Table Columns and Activating the Favorites Icon](abi_ug_table_operations.md) to learn how to use the **Manage Columns** control.
2.  Click the **Pencil \(edit\) icon** and the click the **View Results** to view the newly customized columns.
3.  Click **Hide Results**.
4.  Click **Update** to view the newly customized column view. The report with the newly customized columns displays. The ABI report owner can now share this globally customized report with other ABI users who will see the globally customized column view.

    **Note:** When the report owner shares the report with the globally customized columns with other ABI users, recipients can still configure their own personal views, BUT if the recipient clicks **Restore to Default**, the Default view is the globally customized report view.
