# Viewing Wafer Maps

From the Wafer Map gallery, you can select a specific map to drill down into the measurements taken of the wafer.

Each cell in the Wafer Map is drawn with a color representing relevance among measurement points. The algorithm to determine the color of a cell is based on weighted average calculations of all the measurement points in the wafer map.

1.  To view an individual Wafer Map, click on a thumbnail in the Wafer Map gallery.

2.  Place the cursor over cells in the map to see the precise measurement for each cell.

    **Tip:** You can use the scroll wheel or track pad to zoom into cells.

3.  Adjust the **Control Hi** and **Control Lo** values by using the **+** and **-** buttons, or enter a specific value into the field.

    To reset the values, click **Reset max/min value**.

4.  Click **View SQL** to see the SQL query used to fetch the data currently visible on the screen.

5.  Click **Export** to save the Wafer Map as an image file.

6.  Click **Back to Wafer Maps** to return to the Wafer Map gallery.
