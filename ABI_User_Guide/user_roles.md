# User Roles

Users of the ABI application are assigned one or more of four different user roles. Different actions are available to each of the user roles.

User roles are assigned at the site level by the site administrator.

|Role|Permissions|
|----|-----------|
|User|Can access the application to visualize warehouse data.|
|Admin|Can access the application like a user as well as additional Administration functions.|
|Chart Admin|Can elevate charts to be standard charts for a report type \(must also have User or Admin role\).|
|PLY Admin|Can view and edit class code designations for defects in the PLY Image Gallery.|

**Note:** ABI users must be members of the **ABIAPP\_PLY\_ADMIN\_TEST** bluegroup to be designated the **PLY Admin** User Role.
